DeviceKeeper —— 设备守护
=========================

防止误点任务栏「安全删除硬件」弹出内置 USB 设备(如希沃一体机的无线网卡、
前面板 USB 集线器),误弹即断网/接口失效,本工具通过修改注册表让这些设备
从弹出列表消失,并持续守护防止系统还原。

=====================================================================
零、快速部署(拷贝即用 · 学校班级电脑)
=====================================================================
前提:exe 已在你的开发机上编译好(见下方「一、首次使用」)。

1. 把整个 DeviceKeeper 文件夹拷到 U盘。
2. 到班级电脑,把文件夹复制到本地(如 C:\DeviceKeeper)。
3. 双击 DeviceKeeper.exe → 弹出 UAC 点「是」→ 右下角出现托盘图标。
4. 双击托盘图标 → 浏览器打开控制台 → 点右上角「刷新」。
5. 核对设备列表与系统托盘:先点开任务栏「安全删除硬件」看有哪些设备;
   再看控制台列表(排除强度默认「宽松」,应与系统托盘基本一致)。
   · 若控制台列表少了系统托盘里的设备 → 把「排除强度」切到「宽松」或「关闭排除」再刷新。
6. 找到学校的 USB 网卡 / 前面板集线器 → 点「守护」。
7. 勾选「开机自启」→ 之后重启自动守护,无需再操作。

  · 守护立即生效:守护后马上打开任务栏「安全删除硬件」,该设备应已消失。
    (个别机型若不立即消失,重新插拔一次设备或重启电脑即可)
  · 数据独立存放:每台班级机的 C:\ProgramData\DeviceKeeper\,互不干扰。
  · 首次运行若 SmartScreen 拦截(本地无签名),点「更多信息」→「仍要运行」。
  · 若班级机装了还原卡,需把该数据目录加白名单,否则还原后需重新守护。

=====================================================================
一、首次使用(三步)
=====================================================================
1. 生成主程序:
   双击 根目录的「编译程序.bat」  →  会在本目录生成 DeviceKeeper.exe
   (用系统自带编译器,约 3~5 秒,无需安装任何东西)
   ※ 注意:build 文件夹里的 app.manifest / tray.cs 是编译用的源文件,
     不需要(也不应该)双击打开它们,双击「编译程序.bat」这一个就行。

2. 启动:
   双击 DeviceKeeper.exe
   首次会弹出 UAC 提权框 → 点「是」(守护需要写注册表,必须管理员)

3. 打开界面:
   右键点击右下角托盘图标,或双击图标 → 浏览器打开控制台

=====================================================================
二、界面操作
=====================================================================
- 设备列表:列出当前"可能出现在「安全删除硬件」"的设备
- 排除强度(设备列表右上方,三档可切换):
    · 严格      只显示经典的"可移除且需安全删除"设备(对应博客里的网卡情形)
    · 宽松(荐) 与系统「安全删除硬件」托盘规则一致,WiFi / Billboard 等在此可见
    · 关闭排除  不按能力位过滤,列出全部在线 USB 设备,供人工挑选
  切换后立即生效并记住选择。若托盘里有设备却在列表里看不到,切到「关闭排除」即可。
- 守护:点「守护」后,该设备从「安全删除硬件」消失,但照常工作
  程序按设备情况自动选择手法(日志里会写明):
    · 有 REMOVABLE 位 → 原值减 4(清除可移动位,即博客做法)
    · 无 REMOVABLE 位 → 原值加 128(标记为可意外拔出),并额外写
      Device Parameters\SurpriseRemovalOK=1
  写入前必定备份,写入后必定回读校验;不符会自动回滚原值。
  ★ 注册表改完不等于设备已采用:系统要重新枚举该设备才会生效。
    因此守护成功后默认会自动「重启该设备」(约 1 秒),让变更立即生效。
    该行为可在「启动设置」里用「守护后自动重启该设备」开关控制。
- 使生效:设备行右侧的按钮,手动重启该设备以应用变更(网络设备会瞬断约 1 秒)
- 刷新托盘:日志卡右上方按钮,重启资源管理器(explorer.exe)强制系统托盘重建。
  任务栏会短暂闪烁,属正常现象。仅在「重启设备」仍无效时作为兜底使用。
- ⚠ U盘 / 移动硬盘:它们的「可弹出」来自存储媒体层,不是普通设备节点,
  **改注册表无法把它从托盘移除**(已实测确认)。本工具适用于 USB 网卡、
  USB 集线器这类单一 USB 设备。列表里存储设备已标注提示。
- 解除守护:还原注册表原值(含 SurpriseRemovalOK),操作前自动备份,可一键恢复
  (解除设备不会再自动关闭守护引擎)
- 守护引擎:总开关,关闭后停止自动修复(设备重启后自然恢复原值)
- 开机自启:开机静默守护 + 登录显示托盘,全程不弹任何窗口
- 累计守护次数:记录系统写回被自动修复的次数

=====================================================================
三、目录结构
=====================================================================
DeviceKeeper.exe   主程序(托盘 + 启动器)
node.exe           内置运行时(请勿删除)
server.js          后端服务逻辑
public/            网页界面
assets/icon.ico    图标
build/             源码与编译脚本
数据目录(自动创建):C:\ProgramData\DeviceKeeper\
  config.json      守护配置
  backups\         每次守护前的注册表原值备份(.reg)
  logs\app.log     操作日志

=====================================================================
四、到校验收清单(重要!)
=====================================================================
在真实教室机上按顺序验证:

[ ] 1. 双击 DeviceKeeper.exe,点「是」通过 UAC
[ ] 2. 双击托盘图标打开控制台,对比系统托盘核对设备列表
      (列表不全 → 排除强度切「关闭排除」再刷新)
[ ] 3. 点「守护」目标设备(如 USB 网卡 / 前面板集线器)
      成功后日志会写明用的哪种手法,并显示"守护成功 ... → ...(备份:...)"
      程序会自动重启该设备让变更生效;若提示自动重启失败,点设备行的「使生效」
[ ] 4. 打开任务栏「安全删除硬件」→ 该设备已消失
      若仍在:先点该设备行的「使生效」;仍无效再点日志卡的「刷新托盘」
[ ] 5. 网络/设备功能正常(守护 ≠ 禁用,设备应照常用)
[ ] 6. 勾选「开机自启」→ 重启电脑
[ ] 7. 重启后:任务栏托盘图标自动出现,设备仍不在弹出列表,守护引擎"运行中"
[ ] 8. 尝试「解除守护」→ 设备重新出现在弹出列表,原值已还原
[ ] 9. 查看日志,操作均有记录

故障排查:
- 软件不生效/有异常时,点控制台「导出日志」按钮 → 会生成一份完整诊断
  报告(txt),里面包含:系统信息、排除强度、守护配置(含每台设备的手法与原值)、
  当前设备清单(含能力位解码)、完整操作日志。把这个 txt 文件拷回来发给开发者,
  即可精准定位问题,无需现场截图。
- 守护失败时日志一定留有记录,格式为「守护失败[原因] 设备ID | 细节 | 输出」,
  例如:守护失败[写入注册表失败] USB\VID_xxxx\... | 手法=mark-surprise |
  目标值=128 | 输出:拒绝访问 | 备份已在:...reg。凭这行即可判断是权限、
  杀软拦截还是设备问题。
- 日志也会自动保存在 C:\ProgramData\DeviceKeeper\logs\ 下,每次启动一个
  独立的 devicekeeper-时间戳.log 文件,app.log 是滚动主日志。
- 提示"只读模式" → 未以管理员运行,右键 exe 以管理员身份运行
- 守护失败提示"拒绝访问" → 用「开机自启」的 SYSTEM 服务跑(开机后自动生效)
- 端口被占用 → 检查是否重复运行,或改 server.js 里的 PORT
- 托盘不显示 → 确认 exe 未被安全软件拦截(本地无签名,SmartScreen 可能提示)

=====================================================================
五、卸载
=====================================================================
控制台里逐台「解除守护」→ 关闭「开机自启」→ 右键托盘「退出」→ 删除本目录。
(即便直接删目录,受守护设备也会在下次重启后自动恢复原值,无残留风险)
